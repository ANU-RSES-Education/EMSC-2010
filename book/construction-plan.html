Three-Phase Course Structure

Phase 1: Foundational Skills (Weeks 1-4)

NoteMastery Learning Approach

Ensures all students, not just the best, master essential skills before progressing to project work.

Format: 2 × 2-hour practicals + 1-hour tutorial per week Assessment: Weekly quizzes (unlimited attempts, hurdle requirement)

Content Development Status

Week 1: Introduction and Setup - ⏱️ Practical 1: Course intro, environment setup, first Python program - ⏱️ Practical 2: Jupyter notebooks, markdown, basic plotting - ⏱️ Tutorial: Course overview, problem-based learning introduction - ⏱️ Example dataset for first visualization

Week 2: Data Fundamentals - ⏱️ Practical 1: Data structures, reading files, pandas introduction - ⏱️ Practical 2: Data cleaning, quality assessment - ⏱️ Tutorial: Quiz 1 support, data quality concepts - ⏱️ Quiz 1: Python basics (question bank) - ⏱️ Climate dataset example

Week 3: Analysis and Visualization - ⏱️ Practical 1: Data transformation, statistical summaries - ⏱️ Practical 2: Advanced visualization, publication-quality plots - ⏱️ Tutorial: Quiz 2 support, statistical concepts - ⏱️ Quiz 2: Pandas and data manipulation (question bank) - ⏱️ Seismic and spatial datasets

Week 4: Version Control and Collaboration - ⏱️ Practical 1: Git fundamentals, repositories, commits - ⏱️ Practical 2: GitHub workflows, pull requests, collaboration - ⏱️ Tutorial: Quiz 3 support, collaborative coding practices - ⏱️ Quiz 3: Git/GitHub and collaboration (question bank) - ⏱️ GitHub Classroom setup - ⏱️ Team formation strategy

Phase 2: Collaborative Problem-Based Learning (Weeks 5, 7-12)

Format: 2-hour lectorial + 3-hour practical per week Assessment: GitHub collaborative task (15%) + Team lab notebooks (5%)

TipStudent Agency

Students select problems that are relevant and exciting to them from Earth and Environmental Sciences.

Content Development Status

Week 5: Project Launch - ⏱️ Lectorial: Introduction to problem-based learning - ⏱️ Practical: Team formation, problem brainstorming - ⏱️ GitHub collaborative task specification - ⏱️ Lab notebook template and guidelines - ⏱️ Curated project topics and data sources

Week 6: Mid-semester Break - No scheduled classes

Week 7: Statistical Foundations - ⏱️ Lectorial: Hypothesis testing, p-values, significance - ⏱️ Practical: Statistical tests with team data - ⏱️ Notebook: Common statistical tests - ⏱️ Earth Science statistical examples

Week 8: Prediction and Forecasting - ⏱️ Lectorial: Time series, trend detection, uncertainty - ⏱️ Practical: Time series analysis, forecasting - ⏱️ Notebook: Time series methods - ⏱️ Climate/environmental time series datasets

Week 9: Modeling and Simulation - ⏱️ Lectorial: Introduction to modeling, validation - ⏱️ Practical: Building models, sensitivity analysis - ⏱️ Notebook: Simple Earth Science models - ⏱️ Example models (population, diffusion)

Week 10: Optimization and Resource Allocation - ⏱️ Lectorial: Optimization, sample size, error propagation - ⏱️ Practical: Optimization examples, power analysis - ⏱️ Notebook: Optimization methods - ⏱️ Sampling strategy examples

Week 11: Causation and Attribution - ⏱️ Lectorial: Correlation vs causation, regression - ⏱️ Practical: Regression analysis, multivariate methods - ⏱️ Notebook: Regression and attribution - ⏱️ Climate attribution case study

Week 12: Advanced Topics - ⏱️ Lectorial: ML introduction, spatial statistics, presentation skills - ⏱️ Practical: Project finalization, report writing - ⏱️ Notebook: ML basics (sklearn) - ⏱️ Presentation guidelines and rubric

Phase 3: Individual Application (Weeks 8-12 + Exam Period)

Assessment: Individual project plan (25%) + Project report/presentation/showcase (40%)

Key Pedagogical Principles

Mastery Learning

  • Unlimited quiz attempts in weeks 1-4
  • Ensures all students reach required standard
  • Equitable foundation for complex work

Problem-Based Learning

  • Student agency in problem selection
  • Real Earth & Environmental science context
  • Encourages ownership and engagement

Scaffolded Progression

  • Foundation → Collaboration → Independence
  • Team work builds confidence
  • Individual work demonstrates mastery

Modern Practice

  • AI tools encouraged with critical evaluation
  • Collaboration reflects scientific practice
  • Version control for accountability
